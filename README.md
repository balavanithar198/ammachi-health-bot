# Ammachi Health Bot

Ammachi Health Bot is a diabetes-conscious, Tamil-first cooking assistant designed to help families enjoy traditional recipes without losing the taste and identity of home-style Tamil food.

This project is a Vite + React + TypeScript web app focused on making traditional meals more health-aware, especially for people managing diabetes and other nutrition-sensitive conditions.

## Why this project exists

Traditional Tamil meals often rely on ingredients and cooking methods that can be difficult to adapt for healthier eating. Ammachi Health Bot aims to turn that challenge into a guided, culturally respectful experience by helping users:

- understand healthier ingredient swaps
- identify diabetes-conscious alternatives for common Tamil dishes
- preserve cultural food preferences while reducing risk factors
- explore practical meal guidance in a simple, accessible interface

## Features

- Tamil-first, culturally aware food guidance
- diabetes-conscious recommendations for traditional recipes
- clean, responsive interface for mobile and desktop users
- fast frontend experience powered by Vite and React
- modern styling with Tailwind CSS

## Getting started

### Prerequisites

- Node.js 18 or later
- npm 9 or later

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

This starts the Vite development server. The app will typically open in the default browser or can be accessed from the local Vite URL shown in the terminal.

### Build for production

```bash
npm run build
```

The production build output is generated in the `dist/` directory.

### Preview production build

```bash
npm run preview
```

## Available scripts

```bash
npm run dev      # start local development server
npm run build    # type-check and build production bundle
npm run preview  # locally preview the production build
npm run lint     # run Oxlint checks
```
